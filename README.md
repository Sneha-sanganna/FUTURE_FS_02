# Client Lead Management System (Mini CRM)

A simple web-based CRM application for managing client leads generated through website contact forms.

## 📌 Project Overview

The Client Lead Management System is a CRM application designed to help administrators manage leads generated from website contact forms.

The system allows administrators to view, add, update, and delete leads, track lead status, and maintain notes and follow-ups.


## ✨ Features

- 🔐 Admin Login

- 👥 Lead Management

- 📋 Lead Listing

- ➕ Add New Leads

- ✏️ Edit Lead Information

- 🗑️ Delete Leads

- 🔄 Update Lead Status

  - New

  - Contacted

  - Converted

- 📝 Add Notes

- 📅 Follow-up Management

- 💾 MongoDB Database Integration
